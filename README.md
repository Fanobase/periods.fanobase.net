# Quantum periods of Fano fourfolds

The public catalogue combines CKP, Kalashnikov and
[type-a.fanobase.net](https://type-a.fanobase.net/).

This repository contains the generated public website and downloads.
It contains no private research inputs or working-repository history.
GitHub Actions verifies the export and publishes it through GitHub Pages.

Public data files are listed with SHA-256 hashes in `public-export.json`.
Updates are produced with the public exporter in the separate working repository;
only the checked public output is copied here.
